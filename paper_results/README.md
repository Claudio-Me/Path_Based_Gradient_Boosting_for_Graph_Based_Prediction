# Published results

The numbers reported in the manuscript, together with the runs they came from.
Everything here is generated by:

```bash
python tools/collect_paper_results.py --write
```

That script also **audits** the numbers: it searches the stored result CSVs for a
run reproducing each published value to the precision at which it was printed,
and reports anything it cannot find. Nothing here is inferred from a
near-matching run.

## Files

| File | Paper artifact | Produced by |
|------|----------------|-------------|
| `table1_dataset_characteristics.csv` | Table 1 | `python dataset_analysis.py` → `dataset_summary.csv` |
| `table2_accuracy.csv` | Table 2 (accuracy, 5 methods) | `run_pathboost.py`, `run_gnn.py`, `run_kernel.py` |
| `table3_f1_macro.csv` | Table 3 (F1-macro, PathBoost vs GINE) | `run_pathboost.py`, `run_gnn.py` |
| `table4_regression.csv` | Table 4 (alchemy_full regression) | `run_pathboost_regression_alchemy.py alchemy_full` |
| `figure1_proteins_full_subsample.json` | Figure 1 (learning curve) | `subsample_dataset/run_evaluation.py --dataset PROTEINS_full` |
| `provenance.csv` | audit trail: published value → run file → status | `tools/collect_paper_results.py` |
| `raw/` | the run files the values were traced to | copied by the same script |

## Traceability status

`provenance.csv` carries one row per published value with a `Status` column:

- **traced** — a stored run reproduces both the mean and the standard deviation.
- **mean only** — the mean matches but the stored standard deviation differs.
- **time limit** — the paper reports no value (the 20-hour budget was exceeded).
- **NOT TRACED** — no stored run reproduces the value in the directories searched.

The classification and regression experiments were executed on the university
compute servers (see §3.6 of the paper). The per-run CSVs for the graph-kernel
baselines are archived here; the PathBoost and GINE runs behind Tables 2-4 were
produced on those servers and are being restored from them. Re-run the collector
with the synced directory to complete the audit:

```bash
python tools/collect_paper_results.py --extra-dir /path/to/synced/results --write
```

## Note on Table 1

`table1_dataset_characteristics.csv` reports the graph counts **as printed in the
paper** (`Graphs_paper`) next to the counts **recomputed by `dataset_analysis.py`
from the downloaded TU datasets** (`Graphs_recomputed`). They agree for nine of
the twelve datasets and differ for three Tox21 splits:

| Dataset | Table 1 | recomputed |
|---------|---------|------------|
| Tox21_ARE_eval | 970 | 552 |
| Tox21_ARE_train | 5670 | 7167 |
| Tox21_MMP_train | 5418 | 7320 |

All other columns (average nodes and edges, feature counts, class balance,
number of categorical attribute classes) agree exactly. Both figures are kept
here rather than silently reconciled.
